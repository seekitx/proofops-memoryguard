01 / WHY IT MATTERS

A risk control that resets every chat is not a control.

Most Agent demos remember preferences. MemoryGuard remembers the fact that must change authority: a revoked target, an open dispute, or a cap learned in another session.

The model may explain. It never grants permission. Exact Sibyl entities feed a deterministic decision kernel; untrusted free text stays quarantined.

01

Observe ≠ trust

Typed facts can be accepted. External instructions are hashed and quarantined, never promoted into authority.

02

Recall causes the diff

The response names the exact memory IDs that changed READY into DENY across sessions.

03

Finalize, then prove

Only a fixed proof root can be sent to Base. The backend verifies the receipt before showing “verified”.
